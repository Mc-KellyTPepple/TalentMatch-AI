# TalentMatch AI

### AI-Powered Resume-to-Job Matching and Interview Preparation Platform

TalentMatch AI is an intelligent recruitment and career platform that analyzes a candidate's resume and identifies relevant job opportunities using semantic AI, keyword matching, and hybrid ranking.

The platform is designed to demonstrate how AI can assist candidates and employers in understanding candidate-job compatibility.

---

## Key Features

### Resume Analysis

Candidates can upload:

- PDF resumes
- DOCX resumes
- TXT resumes

The system extracts the resume content in memory without permanently storing the uploaded document.

---

### AI Job Matching

TalentMatch AI combines:

- Semantic similarity
- TF-IDF keyword similarity
- Hybrid ranking

to identify jobs that are most relevant to a candidate's resume.

---

### Match Score

Each recommended job receives an interpretable compatibility score.

Example:

```text
92% — Excellent Match
78% — Strong Match
63% — Moderate Match
48% — Developing Match
